
#COVID-19 Detection from Chest X-ray using DenseNet50

A deep learning project for detecting COVID-19 from chest X-ray images using the DenseNet50 architecture and TensorFlow. The application allows users to upload X-ray images and receive predictions through a simple Streamlit web interface.

---

##Features

- Chest X-ray image classification
- COVID-19 detection using DenseNet50
- Image preprocessing with OpenCV and Pillow
- Interactive Streamlit web application
- Fast and user-friendly interface
- Deep learning-based medical image analysis

---

##Technologies Used

- Python
- TensorFlow
- NumPy
- OpenCV
- Pillow
- Streamlit
- Pandas

---

##How to Run the Project

1. Clone the Repository
git clone 
2. Navigate to the Project Directory
cd COVID-Xray-DenseNet50
3. Install Dependencies
pip install -r requirements.txt
4. Run the Streamlit Application
streamlit run app.py
